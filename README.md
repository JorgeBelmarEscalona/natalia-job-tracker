# Seguimiento de Postulaciones

Tablero simple para registrar ofertas laborales (control de gestión / finanzas) y el estado de cada postulación.

- Los datos se guardan en el navegador del dispositivo que lo usa (localStorage), no en un servidor.
- Usa los botones **Exportar** / **Importar** para respaldar la información o pasarla a otro computador.
- Publicado con GitHub Pages: ver el sitio en la pestaña "About" del repositorio una vez habilitado.
